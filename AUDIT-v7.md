# Admin Production Baseline v7 — Tournament Director Card View

Card View redesigned around director decisions, not Player 1 hierarchy.

At a glance each card now shows:
- registration status and reference
- action-needed / ready indicator
- Player 1 and Player 2 with identical typography
- assigned division
- eligibility / verification state
- payment state
- submitted date/time
- View Record
- permitted status control

The whole card opens the registration record except when interacting with buttons/selects.

No Player or API change required.
Compatible with API contract 2026.09.10.2.
