# Admin Production Baseline v4 — Registration Search

Search is available above both Card View and List View.

Searches:
- registration reference
- registration status
- Player 1 / Player 2 names
- both emails
- both mobile numbers
- club affiliation
- jersey back names
- DUPR IDs / ratings
- requested / organizer-validated levels
- category / division
- payment method
- payment status
- payment reference
- sender name
- amount paid
- payment date

UX:
- instant debounced search
- result count
- clear button
- Escape clears search
- search focus/caret preserved after results refresh
- works together with Status and Division filters
- applies to both Card View and List View

No API or Player changes required.
Compatible with API contract 2026.09.10.2.
